      About Probability Playground

      Probability Playground is an educational simulation laboratory. Every experiment here uses your browser's pseudorandom number generator (with an optional cryptographic-quality mode) to simulate chance events — coin flips, dice rolls, shared birthdays, random walks, and more.

      Outcomes in any single run will vary because of randomness. That's the point: watching short-run noise settle into long-run patterns is how probability becomes intuitive instead of abstract. Run enough trials and the observed results should approach the theoretical predictions, wherever the model's assumptions hold.

      This is not financial, gambling, or professional statistical advice. All money values used in the Expected Value Lab are fictional and for illustration only.

      Built as a static, backend-free web app. No accounts, no tracking, no server.
